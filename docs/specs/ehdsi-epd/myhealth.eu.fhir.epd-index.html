Scope

This IG is a proof of concept, specifying a set of rules to be applied to HL7 FHIR to define how to represent a ePrescription and eDispensation for the European cross-borders exchange, coherently with the MyHealth@EU requirements catalogue and specifications prepared by HL7 Europe and Xt-EHR project.

This guide is derived for the HL7 Europe Medication Prescription and Dispense HL7 FHIR IG fulfilling the MyHealth@EU Functional Requirements.

MyHealth@EU

Current ePrescription and eDispensation service in MyHealth@EU is operational since 2019 and is based on HL7 CDA. This IG serves as a proof of concept for implementing the same service using HL7 FHIR.
