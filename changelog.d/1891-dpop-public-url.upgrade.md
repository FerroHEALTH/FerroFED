- `[auth.dpop] external_url` is removed and refused as an unknown key. A `DPoP` proof's `htu` is compared with the origin of `gateway.public_url`, the request's whole path appended, so `[auth.dpop]` needs `gateway.public_url` and is refused without it. Upgrade: delete `external_url` from `[auth.dpop]`, and set `gateway.public_url` to the URL clients reach the gateway at, with the base path (#1891).
