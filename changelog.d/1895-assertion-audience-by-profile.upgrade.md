- `assertion_audience` is removed from every `credentials.oauth` table and refused as an unknown key. A `private_key_jwt` client assertion takes its `aud` and `typ` from the grant's `security_profile`: a plain grant names the token endpoint under `typ` `JWT` (SMART App Launch 2.2.0, Client Authentication: Asymmetric), and a `security_profile = "fapi2"` grant names the issuer identifier as one string under `typ` `client-authentication+jwt` (FAPI 2.0 Security Profile §5.3.3.1; RFC 10070 §4). Upgrade: delete `assertion_audience`; a table that set it to `issuer` for a FAPI 2.0 authorization server sets `security_profile = "fapi2"` if it does not already (#1895).
