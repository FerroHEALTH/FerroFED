- Under `[eehrxf.terminology] transcode = "myhealth-eu"`, a member of `Electronic-Dispensations` can name the code systems it records (`systems` in its `[[fhir.serve]]` table). A dispensation it owns is translated into them through the terminology server before it is written, exact matches alone, after the codings sent; a concept no exact translation reaches is refused `422` naming its element path and code systems, with nothing sent to the member (#2084).
