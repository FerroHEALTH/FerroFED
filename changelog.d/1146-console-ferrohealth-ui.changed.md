- The operator console draws with `ferrohealth-ui` 0.1.3, the component
  library the four FerroHEALTH consoles share. It keeps only its "Azure &
  Iron" brand theme, which the server serves beside the library's
  stylesheet; the console's Tailwind stylesheet, style and component modules,
  highlighter and icon crates are gone. The top bar carries one theme
  toggle, a moon in the light theme and a sun in the dark one, which posts
  with no script and swaps the theme in place once the page hydrates; a
  page with no theme cookie now follows the system. The query console takes
  its AQL in a highlighted editor with numbered lines, and Offset and Fetch
  say what an empty field means. A configuration form opens with a
  breadcrumb back to its tab. The credentials form
  shows the settings of the grant chosen. The listing tables stack their
  rows as cards on a phone and leaves out a column no row fills, the selects draw
  the library's chevron, cards side by side keep their own heights, the top
  bar keeps one row on a phone, and every screen reads at 390 CSS pixels as
  well as 1440.
